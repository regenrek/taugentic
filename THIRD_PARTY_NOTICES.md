## GPUIX

The Taugentic desktop uses `@regenrek/gpuix-react` version
`0.5.0-regenrek.3` and its matching native packages. These packages are
published from the [regenrek/gpuix](https://github.com/regenrek/gpuix) fork
because Taugentic requires additional native desktop features. The fork is
based on the upstream `@gpuix/react` and `@gpuix/native` packages from
[GPUIX](https://github.com/remorses/gpuix).

Copyright 2026 remorses

GPUIX is licensed under the Apache License 2.0. Its native package includes
GPUI and the pinned `alacritty_terminal` fork from Zed, which are licensed
under the Apache License 2.0.

GPUIX ports text selection, syntax highlighting, Markdown, diff rendering,
theme code, and caret behavior from
[Comet](https://github.com/zeronsh/comet). Comet is licensed under the MIT
License. Copyright 2026 Wing.

The native package uses Syntect and its bundled syntax definitions. The full
set of component licenses is recorded in GPUIX's notice file.

The full GPUIX license and component list are included in
`third_party/gpuix/LICENSE` and `third_party/gpuix/THIRD_PARTY_NOTICES.md`.
